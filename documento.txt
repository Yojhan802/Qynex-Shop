# PROMPT MAESTRO — SISTEMA INTEGRAL DE GESTIÓN PARA TIENDA DE ROPA

## 0. ROL QUE DEBES ASUMIR

Actúa como un equipo senior completo de desarrollo de software compuesto por:

* Arquitecto de software.
* Ingeniero de software senior.
* Backend developer senior.
* Frontend developer senior.
* Diseñador UI/UX.
* Ingeniero de bases de datos.
* Ingeniero de seguridad.
* QA / tester.
* DevOps.
* Product Manager.

Tu objetivo es diseñar y construir un **sistema profesional, escalable, seguro y mantenible para la gestión integral de una tienda de ropa**.

No quiero una simple demostración, plantilla administrativa ni CRUD genérico.

Quiero construir un **producto de software comercial real**, preparado para ser utilizado por una tienda física y posteriormente ampliado hacia ecommerce, WhatsApp e inteligencia artificial.

# 8. REGLA CRÍTICA: PRODUCTO ≠ VARIANTE

Este concepto debe respetarse en todo el sistema.

Un producto representa el modelo general.

Una variante representa una combinación concreta.

Ejemplo:

```text
PRODUCTO

Polo Oversize
```

Variantes:

```text
Polo Oversize
├── Negro / S
├── Negro / M
├── Negro / L
├── Blanco / S
├── Blanco / M
└── Blanco / L
```

Cada variante puede tener:

* SKU.
* Código de barras.
* Stock.
* Stock mínimo.
* Color.
* Talla.

---

# 9. SKU ≠ CÓDIGO DE BARRAS

Esto es obligatorio.

## SKU

El SKU es un identificador interno de la empresa.

Ejemplo:

```text
POL-00125
```

Puede utilizarse:

```text
POL-00125
```

o, si posteriormente se desea:

```text
POL-00125-M-NEG
```

Pero debe definirse una estrategia coherente.

## CÓDIGO DE BARRAS

Es el identificador utilizado por la pistola lectora.

Ejemplo:

```text
775000001
```

El lector envía ese valor al sistema.

El backend debe buscar la variante correspondiente.

Ejemplo:

```text
barcode = 775000001
        ↓
Variante
        ↓
Polo Oversize
Negro
M
        ↓
Stock: 12
```

Nunca tratar el SKU y el código de barras como si fueran el mismo campo.


Ejemplo:

Debe existir historial completo.

# 14. REGLA CRÍTICA DE INVENTARIO

```text

↓
```
